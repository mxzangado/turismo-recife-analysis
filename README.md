# Análise de Satisfação Turística - Recife 🏖️

Este projeto analisa o nível de satisfação de turistas em Recife com base em avaliações de hospedagem, gastronomia, transporte e atrativos.

## 📊 Principais Insights
* **Fator de Encantamento:** A satisfação com os **Atrativos** é o que mais influencia a média geral ($r = 0.48$).
* **Independência de Serviços:** Não há correlação forte entre a qualidade da hospedagem e da gastronomia ($r = 0.11$), indicando experiências isoladas.
* **Perfil por Nacionalidade:** Turistas da Itália apresentam a maior média de satisfação, enquanto a França apresenta a menor.

## 🛠️ Tecnologias Utilizadas
* **Python 3.11**
* **Pandas:** Limpeza e manipulação de dados.
* **Seaborn & Matplotlib:** Visualização de dados e regressão linear.
* **Jupyter Lab:** Ambiente de desenvolvimento.
